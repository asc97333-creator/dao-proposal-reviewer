# GenLayer Projects submission draft

Name: AI DAO Proposal Reviewer

## Description (under 1000 characters)

AI DAO Proposal Reviewer is a GenLayer Intelligent Contract prototype for reviewing DAO proposals. Users submit proposals, and AI produces advisory summaries, benefits, risks, and missing information. Validators assess the review against the original proposal and explicit criteria. Only the deploying organizer can record the final decision. Studio sandbox deployment, proposal submission, AI analysis, and organizer decision have been verified, including a rejected unauthorized decision attempt. The responsive website is an offline educational demo, not a connected on-chain client. The prototype does not execute proposals, transfer tokens, or implement DAO voting.
