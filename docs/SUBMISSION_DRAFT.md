**Name:** AI DAO Proposal Reviewer

**Description (under 1000 characters):**

AI DAO Proposal Reviewer is a GenLayer Intelligent Contract prototype that improves how DAOs review governance proposals. A participant submits a proposal, and GenLayer's comparative AI validation produces an advisory review covering benefits, risks, and missing information. The contract records the proposal and analysis on-chain. Only the deploying organizer can record a final decision, keeping AI recommendations separate from governance authority. The project includes a responsive educational website and open-source contract. The website is currently an offline demo, and the contract has not yet been independently verified in GenLayer Studio. The project does not execute proposals, distribute rewards, or implement DAO token voting.
